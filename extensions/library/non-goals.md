# Non-goals

The initial Library Extension does not standardize:

- a vector database implementation;
- embedding models;
- a network transport;
- an authentication protocol;
- a package registry service;
- a specific filesystem technology;
- a specific agent framework;
- a cross-provider relevance-score normalization algorithm;
- distributed transaction semantics for writable providers.

These may be implemented by adapters or later extensions without changing the core Library model.
