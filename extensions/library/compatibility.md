# Upstream Compatibility

This extension intentionally does not redefine Open Knowledge Format Core document semantics. OKF Core remains the normative format for OKF documents and bundles.

Library functionality adds distribution, runtime organization, semantic navigation, provider capabilities, and lifecycle concepts that are outside the core document representation.

If upstream OKF later standardizes overlapping registry, mount, catalog, or provider concepts, this extension should converge on upstream terminology and deprecate redundant definitions rather than preserve incompatible parallel concepts.
