# Glossary

- **Library**: an independently identifiable knowledge unit conforming to the Library Extension.
- **Runtime**: the host that registers, mounts, routes, and aggregates Libraries.
- **Registry**: runtime state describing resolved and mounted Libraries.
- **Provider**: capability implementation used by a Library for content, catalog, query, maintenance, or related operations.
- **Source**: description of how a Library can be obtained or resolved.
- **Catalog**: semantic navigation structure contributed by a Library.
- **Knowledge Node**: logical node in a Library namespace; it may or may not correspond to a physical file.
- **Virtual Node**: node whose content or children are produced dynamically by a provider.
- **Global Catalog**: derived aggregation of mounted Library catalogs.
- **Agentic Query Provider**: query provider that uses an agent to perform multi-step retrieval while preserving evidence and provenance.
