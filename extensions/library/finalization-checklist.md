# Draft Finalization Checklist

Before declaring v0.1 stable:

- reference SDK passes Local, Git, and Virtual architecture tests;
- CLI and MCP expose the same logical Library operations;
- manifest serialization has an implementation-tested schema;
- canonical URI form has round-trip tests;
- query result evidence/provenance is stable;
- unsupported capabilities fail deterministically;
- upstream OKF overlap has been reviewed again;
- Project Context profile can be implemented without core changes.
